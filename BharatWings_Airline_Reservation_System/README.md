# BharatWings - Airline Reservation & Ticket Booking System (India)

## Overview
BharatWings is a full-featured Indian Airline Reservation System built with HTML5, Tailwind CSS, and JavaScript. 
It supports complete CRUD operations (Create, Read, Update, Delete) for Indian domestic flights.

## Included Features
1. **Indian Airlines Schedules Board:** Includes IndiGo, Air India, Vistara, SpiceJet, and Akasa Air.
2. **Interactive Ticket Booking:** Passenger info, Aadhaar/Passport ID, dynamic fare calculation.
3. **E-Ticket Printable View:** PDF-styled Boarding Pass with barcode and Cloud Sync validation.
4. **CRUD Management:** Search, Edit Passenger details, or Cancel Bookings.
5. **Local Storage Cloud Sync Simulation:** Auto-saves data locally.

## How to Run
1. Unzip the downloaded folder.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Edge, Safari).
3. No server or npm build required!
